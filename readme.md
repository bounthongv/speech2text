## Setup

1.  Clone the repository:
    `git clone https://github.com/bounthongv/speech2text.git`
2.  Install Python dependencies:
    `pip install -r requirements.txt`
3.  **Download Required Models:** This project requires the `wav2vec2-large-xlsr-53` model. Please download it from (insert link to Hugging Face or wherever you got it) and place it in a `models/` directory at the root of the project.
4.  **Download FFmpeg:** Download FFmpeg from [https://ffmpeg.org/download.html](https://ffmpeg.org/download.html) and place the executables in a `ffmpeg/bin/` directory.
